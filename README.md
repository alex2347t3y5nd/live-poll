# Live Poll

Современный сервис интерактивных опросов для встреч, презентаций, обучения и мероприятий. Ведущий запускает сессию, участники подключаются по QR-коду, а ответы появляются на экране в реальном времени.

## Возможности

- вопросы с выбором одного из вариантов;
- свободные ответы в формате облака слов;
- подключение участников по короткой ссылке и QR-коду;
- обновление результатов без перезагрузки страницы;
- отдельный полноэкранный режим демонстрации;
- экспорт истории сессии в PDF;
- адаптивный интерфейс для компьютеров и смартфонов.

## Как это работает

В приложении есть три интерфейса:

1. **Ведущий** создаёт сессию и управляет вопросами.
2. **Участник** отвечает со смартфона или компьютера.
3. **Экран** показывает аудитории результаты в реальном времени.

Сервер работает на Node.js и Express. REST API отвечает за создание сессий, вопросов и ответов, а WebSocket — за мгновенную доставку обновлений всем подключённым интерфейсам.

## Быстрый запуск

Потребуется Node.js 18 или новее.

```bash
npm install
npm start
```

После запуска откройте панель ведущего:

```text
http://localhost:3000/presenter.html
```

Ссылки для участников и экрана демонстрации появятся в панели автоматически.

Для разработки с автоматическим перезапуском сервера:

```bash
npm run dev
```

## Структура проекта

```text
public/
  presenter.html   панель ведущего
  participant.html страница участника
  display.html     экран результатов
server.js          API и WebSocket-сервер
```

## Ограничения прототипа

- Сессии и ответы хранятся в памяти и сбрасываются после перезапуска сервера.
- Авторизация и разграничение доступа отсутствуют.
- Один участник ограничивается одним ответом только в рамках открытой страницы.
- Для публичного использования рекомендуется добавить постоянную базу данных, проверку входных данных, защиту панели ведущего и ограничение частоты запросов.

## Технологии

- Node.js, Express;
- WebSocket (`ws`);
- Chart.js;
- QRCode;
- html2canvas и jsPDF.

## Запуск как системного сервиса

Готовый unit-файл для Linux находится в `deploy/live-poll.service`. Он запускает приложение из `/opt/live-poll` на порту `3100` и автоматически перезапускает процесс после сбоя или перезагрузки сервера.
